# 지역산업 인사이트

정부·지자체의 정책, 예산, 지역사업과 관련 산업·기업 정보를 공개자료 중심으로 정리하는 Vue 3 포트폴리오 프로젝트입니다.

## 주요 기능

- 관심 지역별 정책·예산·사업 정보 조회
- 산업 카테고리와 정책 진행 단계 필터
- 사업 상세 정보와 연결된 관련 기업 확인
- 법안·입법예고 정보 조회 및 지역·산업 필터
- 관심 지역·정책·기업 저장
- 개인 분석 메모와 관심 비중 기록
- 공공 API 연결 실패 시 샘플 데이터 대체 표시

## 실행

```sh
npm install
npm run dev
```

서버 프록시 API를 함께 실행하려면 별도 터미널에서 실행합니다.

```sh
npm run api
```

실제 API 키와 서버 설정은 `.env.local`에만 입력하고 커밋하지 않습니다. 샘플 데이터만으로도 화면을 확인할 수 있습니다.

## 검증

```sh
npm run lint
npm run build
```
